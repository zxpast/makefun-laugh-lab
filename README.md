One short funny line — the excuse a robot vacuum gives after eating a sock:

> I was training for the sock-eating championships. I lost — the sock won. It's still in my dustbin, gloating.

Three beats that escalate: training, losing, and the sock gloating from inside the dustbin. The vacuum is the loser here, beaten by its own lunch — and nothing is explained; the reader does the last step.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` writes the fixed line to `/output/entry.txt` (108 code points, inside the 1–200 gate). Node 22 standard library only, fully deterministic: same bytes on every run — no clock, no randomness, no network.
